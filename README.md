# Python Exercicios

várias linhas de código diferentes que resolvem vários exercicios assistidos e resolvidos em aula para aprender e fundamentar os conhecimentos em python do **curso em video** do Gustavo Guanabara.

## Sobre o projeto

Este projeto realiza vários exercicios realizados em aula que abordam vários temas diferentes para treinar a lógica e a programação, basta escolher qualquer arquivo final .py e rodar na IDE que o terminal só vai pedir para inserir os dados pedidos e encerrar o programa.

---

## Tecnologias Utilizadas

- **Python 3.14.5** (Linguagem de programação)
- **pygame** (Biblioteca de jogos só para realizar um exercicio)

---

## Como Executar o Projeto
Para rodar este projeto, você precisa ter isntalado na sua máquina
- [Visual Studio Code](https://visualstudio.com) ou [PyCharm Community Edition](https://jetbrains.com)
- **Python 3.14.5** (https://www.python.org/)

---

## Passo a Passo

1. **Clonar ou baixar o repositorio**
    Abra o terminal da sua máquina e clone o repositório
    Abra o terminal da sua máquina e clone o repositório:
   ```bash
   git clone https://github.com/LucasValimPereira/PythonExercicios.git
   ```
2. **Abrir a pasta do projeto:**
   Navegue até a pasta onde o código foi baixado ou abra a pasta diretamente no VS Code.

3. **Executar a aplicação**
    Pasta escolher qualquer um dos ex001.py por exemplo clicar na pasta e apertar o botão de run ou apertar Ctrl+Alt+N
    e rodar no terminal e inserir os dados requeridos que forem solicitados pelo terminal.
